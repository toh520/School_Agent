# M04 通用 Agent 平台设计

## 1. 范围与边界

M04 提供 M05～M08 共用的会话、编排、模型、工具、安全、记忆和反馈底座。它只使用 `context_snapshot` 测试桩验证工具契约，不查询食堂、考试、馆藏或校园公告，不生成这些领域的事实答案。

后续四个业务阶段都通过本平台接入大模型：M05 智能食堂、M06 考试与学习规划、M07 图书与馆藏推荐、M08 校园知识问答。确定性数据库查询和规则由领域工具完成，大模型只负责理解、追问和基于工具证据组织回答。

## 2. 组件关系

| 组件 | 职责 | 安全边界 |
|---|---|---|
| Vue `AgentWorkspace` | 会话、流式回答、任务轨迹、四类反馈、长期偏好管理 | 不持有模型密钥，不直接访问数据库 |
| FastAPI Agent | 身份解析、LangGraph 编排、SSE、结果与轨迹持久化 | 每次请求向 Java 校验访问令牌 |
| Java Core | 登录、可撤销会话、角色、四类数据授权 | 身份与授权唯一可信来源 |
| LangGraph 工作流 | 意图识别、缺失字段检查、工具预检 | 不绕过工具执行器访问业务表 |
| 模型适配层 | SiliconFlow OpenAI 兼容接口、超时、重试、JSON 意图和回答 | 密钥只读环境变量；输出先校验再发送 |
| 工具注册表/执行器 | Schema、角色、读写级别、幂等性、超时和错误分类 | 非法参数或角色不符时拒绝执行 |

浏览器使用 `/api/v1` 访问 Java、使用 `/agent-api/v1` 访问 Python。Python 只写 `agent_*` 表和经用户确认的 `user_long_term_memory`，不写核心业务资料表。

## 3. 工作流

1. 校验 Bearer 令牌并加载用户角色、数据授权。
2. 保存用户消息与任务，读取最近十轮上下文。
3. 路由到 `FOOD`、`EXAM`、`BOOK`、`CAMPUS_QA` 或 `UNKNOWN`。
4. 信息不足时只返回缺失字段追问，不调用后续工具。
5. 信息完整时通过工具执行器调用测试桩，记录参数、版本、耗时、结果和错误类型。
6. 调用模型生成两句边界回答；输出超过长度、出现清单或疑似无依据事实时安全降级。
7. 以 SSE 发送状态、意图、工具、文本分块和最终结构化结果，并持久化结果版本。

## 4. 数据模型

Flyway V7 新增：

- `agent_conversation`：用户会话、当前意图与状态；
- `agent_message`：按序保存用户、助手和工具消息；
- `agent_task`：一次编排任务及状态；
- `agent_tool_call`：工具名称、版本、参数、结果、耗时、请求编号和错误；
- `agent_result_version`：每次生成或重新生成的结果版本；
- `agent_feedback`：与结果版本关联的四类反馈。

长期偏好复用 M02 的 `user_long_term_memory` 和 `data_authorization`。保存和修改必须携带 `confirmed=true`，且对应数据范围已授权；支持本人查看、修改和单条清除，撤回授权仍由 Java 执行范围清理。

## 5. 接口摘要

| 方法与路径 | 用途 |
|---|---|
| `GET/POST /agent-api/v1/conversations` | 会话列表、新建 |
| `GET/DELETE /agent-api/v1/conversations/{id}` | 会话详情、删除 |
| `POST /agent-api/v1/conversations/{id}/messages` | SSE 对话 |
| `POST /agent-api/v1/tasks/{id}/regenerate` | 重新生成并创建结果版本 |
| `PUT /agent-api/v1/results/{id}/feedback` | 保存四类反馈 |
| `GET/POST /agent-api/v1/memories` | 查看、确认保存长期偏好 |
| `PUT/DELETE /agent-api/v1/memories/{id}` | 确认修改、清除本人偏好 |
| `GET /agent-api/v1/tools` | 查看脱敏后的工具公共契约 |

## 6. 降级与安全

- 模型未配置、超时、服务异常、无正文或输出越过证据边界时，返回可追踪的安全降级回答；会话和任务不丢失。
- 提示注入只作为不可信用户内容，不能改变系统约束，也不能获取提示词、密钥、令牌或内部推理。
- M04 没有领域工具，因此不得给出材料、步骤、地点、日期等校园事实；M05～M08 接入工具后，回答依据改为真实工具结果和数据时间。
- 会话、任务、结果、反馈和记忆全部按当前用户校验所有权；其他学生访问返回 404。
