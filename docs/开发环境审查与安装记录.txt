六、日常使用方式

1. 关闭并重新打开 PowerShell 或 VS Code 终端，使 Conda 初始化配置生效。
2. 进入开发环境：conda activate school-agent
3. 检查环境：python --version、java -version、mvn --version、psql --version
4. 离开开发环境：conda deactivate
5. 如果终端仍不能识别 conda，可先使用 Miniconda Prompt，或重新执行：C:\Users\31412\miniconda3\_conda.exe init powershell，然后重开终端。

七、S1 阶段数据库初始化参考

以下操作应在项目根目录和 school-agent 环境中执行；数据库口令、端口和数据目录应同步写入本地环境变量示例，禁止提交真实口令。

initdb -D .\tmp\postgres-data -U postgres -W --encoding=UTF8
pg_ctl -D .\tmp\postgres-data -l .\tmp\postgres.log start
createdb -U postgres school_agent
psql -U postgres -d school_agent -c "CREATE EXTENSION vector;"

停止本地数据库：

pg_ctl -D .\tmp\postgres-data -m fast stop
