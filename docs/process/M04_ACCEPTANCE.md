## 2. VS Code 非作者验收步骤

1. 在 VS Code 打开仓库根目录，打开 PowerShell，执行 `conda activate school-agent`。
2. 确认 `code/deploy/.env.local` 已填写 `SCHOOL_AGENT_LLM_BASE_URL`、`SCHOOL_AGENT_LLM_MODEL` 和本机模型密钥；不要把文件内容截图、复制到报告或提交 Git。
3. 执行 `./code/tools/test-all.ps1`，确认 Java、Python、Web 检查、生产构建和隔离 Playwright 全部通过。
4. 执行 `./code/tools/start-dev.ps1`，看到完整健康链路成功后访问 <http://127.0.0.1:5173/>。
5. 使用本地学生账号登录，进入“智能助手”；确认页面只显示会话栏、对话区和本轮任务轨迹，不出现“最近安全记录”、Demo、阶段状态或基础服务状态。
6. 新建会话，输入“帮我制定考试复习计划”；确认系统只追问考试时间和科目，不直接生成计划。
7. 继续输入“9月20日考计算机”；确认意图显示“考试与学习规划”，任务轨迹完成，回答明确领域工具尚未接入，不编造复习资料或学校事实。
8. 新建会话并分别输入食堂、图书、奖学金问题，确认识别为智能食堂、图书与馆藏推荐、校园知识问答；任一领域不得输出未经数据库证实的具体清单。
9. 对一条回答依次验证“有帮助、没帮助、内容错误、信息过期”按钮可记录；点击“重新生成”，确认产生新回答且原会话仍可查看。
10. 在“数据授权”开启与该问题对应的授权，回到助手点击“记住条件”，在确认框中确认；检查右侧“已确认偏好”可查看、修改和清除。撤回授权后再保存，应提示先授权。
11. 新建两个学生会话后运行 `npm run test:e2e:live`；确认多轮上下文、其他学生访问 404、反馈、记忆 CRUD、工具契约和删除均通过。
12. 在 VS Code Database Client 查看 `agent_conversation`、`agent_message`、`agent_task`、`agent_tool_call`、`agent_result_version`、`agent_feedback`，确认工具轨迹与结果版本存在，表中没有模型 API Key。
13. 执行 `git check-ignore code/deploy/.env.local`，必须返回该路径；再执行密钥扫描和 `git diff --check`，确认真实密钥未进入差异。
14. 验收结束后执行 `./code/tools/stop-dev.ps1`；由非作者在下方填写结论。
