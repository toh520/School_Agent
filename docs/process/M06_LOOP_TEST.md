## 原始结论（修复前）

闭环专项验收不通过。单轮答案正确和纠错入口可调用，不等于“追问—纠错—再讲解”完整实现；此前单轮测试通过的结论不能扩展为多轮闭环通过。本轮只测试与记录，未修改功能代码。

## 原因定位与待修复项

1. `ExamLearningWorkspace.vue` 的普通 EXPLAIN/SOLVE/DIAGNOSE 请求将 previousAnswer 设为空字符串，仅 CORRECT 携带上一回答。当前协议没有会话标识或多轮历史，普通追问无法可靠指代上一题。
2. 再讲解沿用 CORRECT 模式及原题，缺少独立的追问意图和最新诉求优先级；模型可能重复旧答案，而不是处理最新的对比、换例子或自测要求。
3. 独立审查只接收 mode、question、candidate 和 evidence，没有收到 previousAnswer、correction、workProcess，因而不能完整核查纠错归因、用户最新要求或作答过程。A3 在未完成最新诉求时仍被标记资料支持。
4. 目前审查不通过仅降低验证状态并附加局限，不触发澄清或修复；C3 的错误网络假设仍展示给用户。
5. 应区分原回答错误、用户误解、双方无错但需要补充解释；精确计算结论应明确实现和口径，并用确定性规则或测试样例校验。

## 后续验收标准

同一会话内不重复题干也能正确追问；连续纠错后保留原题和修订；错误质疑不盲从且错误归因准确；再讲解遵循最新要求；上下文缺失时先澄清而非编造；审查能检测上述行为并阻止不合格结果被当成完整通过。
